# Проверки

Пройдены 9 тестов с настоящим PostgreSQL, линтер и форматирование.
Собран React-интерфейс. В Safari проверены открытие страницы, ввод ключа,
получение задания, отправка метки и сообщение «Аннотация сохранена».

Через Docker API выполнено сравнение стратегий: 40 текстов пула, 20 тестовых,
бюджет 12, три seed. Обе стратегии получили accuracy=1 и F1=1 на всех запусках.
Это ожидаемо для простого синтетического набора и не свидетельствует
о превосходстве активного обучения или качестве на реальных текстах.


## Доработка активной очереди

12 тестов прошли: снимок исключает holdout и эталонные метки, сохраняется после
исправления разметки, его порядок действительно используется назначением.
Проверены отсутствие частичного ранжирования при ошибке, восстановление того же
назначения и запрет подмены другого разметчика. React пересобран; персональное
назначение, повтор токена и отправка аннотации проверены через HTTP в Docker.
Новая версия интерфейса проверена сборкой; отдельная визуальная проверка не проводилась.
